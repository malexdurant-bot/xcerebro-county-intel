## tax_foreclosure_resales / sheriff_sales

- 2026-08-23: Found a single public JSON API that resolves both sources at
  once: https://taxsales.lgbs.com/api/property_sales/ (Linebarger Goggan
  Blair & Sampson, LLP — a TX tax-lien law firm that runs this map for many
  counties). No auth, no CAPTCHA, no Playwright — plain `requests` works.
  Standard DRF pagination (count/next/previous/results, limit up to 200
  confirmed).
  - `sale_type=STRUCK OFF` (78 live 2026-08-23) -> tax_foreclosure_resales.
    Richer than the static struck-off PDF originally recon'd: full street
    address, appraised value, minimum bid, all machine-readable.
  - `sale_type` in (SALE, RESALE, FUTURE SALE) (31+0+442=473 live) ->
    sheriff_sales. This resolves the earlier BLOCKED_SOURCE finding on
    dallas.texas.sheriffsaleauctions.com (403 to a plain fetch) — each LGBS
    record's `property_loc` field links directly into that same auction
    site per listing, and the LGBS API itself exposes MORE structured data
    (full address, min bid, appraised value) than the auction site would
    without a real browser session. Built `scrapers/taxsales_lgbs_dallas.py`
    covering both in one script; verified live, both files populated with
    real cause numbers, dollar amounts, and coordinates.
  - config/counties/dallas_tx.json still reflects the OLD source
    descriptions (static PDF for tax_foreclosure_resales, BLOCKED RealAuction
    site for sheriff_sales) — not yet updated to point at this API. Worth a
    config correction pass alongside the court_civil/court_probate updates.

## clerk_recordings / foreclosure_notices

- 2026-08-22: Initial scraper build (scrapers/publicsearch_recorder_dallas.py)
  assumed the PublicSearch SPA would auto-run a search when navigating
  directly to a hand-built `/results?department=...&recordedDateRange=...`
  URL. Live verification showed this is unreliable — the page gets stuck on
  "Loading Results..." and the backend eventually returns "Error While
  Running Search: The request timed out," regardless of whether the
  homepage is visited first in the same browser context.
- Fix: the search must be triggered via real UI interaction — load the
  homepage, click "Recorded Date" to reveal the date fields, fill
  `[aria-label="Starting/Ending Recorded Date"]`, then click the actual
  `<button>` element with text "Search" (not `page.click("text=Search")`,
  which resolves to an unrelated a11y live-region div and hangs for the
  full default timeout). This reliably returns results in ~3-5 seconds.
  Pagination likewise must use the `[aria-label="next page"]` control, not
  a hand-built `&offset=` query param.
- Recording-index lag: on 2026-08-22, searching through "today" (08/22) was
  silently capped by the portal at 08/19 — records appear to land in the
  public index ~3 days after the actual recording date. The scraper's
  default `--days-back` is set to 5 to comfortably cover this lag; dedup on
  `raw_record_id` makes the resulting overlap across daily runs harmless.
- RESOLVED (2026-08-23): the 0-count above was a genuine scraper defect,
  not a sampling artifact. Foreclosure notices do NOT record under the RP
  department at all on this portal. Dallas County Clerk's official
  foreclosures page (dallascounty.org/government/county-clerk/recording/
  foreclosures.php) confirms a structurally separate "Foreclosures" search
  category (department code `FC`), reached via Advanced Search
  (/search/advanced) -> `#docTypes` combobox -> "Foreclosures" option.
  Built a dedicated adapter, `publicsearch_foreclosures_dallas.py`. Verified
  live: 74 unique NOTICE OF FORECLOSURE records over a 5-day recordedDateRange
  window (~15-20/day), each with doc_type, recorded_date, sale_date, doc
  number, and city (the "PROPERTY ADDRESS" column header is misleading — it's
  city-only on the index view, e.g. "IRVING, TEXAS", not a street address).
  The `#docTypes` dropdown option elements report `is_visible()==False` to
  Playwright even when open; must select via `element.evaluate("el =>
  el.click()")`, not a normal `.click()`.
