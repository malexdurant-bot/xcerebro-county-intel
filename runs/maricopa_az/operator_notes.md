## general

**2026-06-26T18:55:00Z** — Phase 0 recon complete for Maricopa County, AZ. Key context:
- Arizona is a NON-JUDICIAL foreclosure state (trustee's sale process under ARS 33-808). There is NO sheriff foreclosure sale calendar. All foreclosure leads originate from the County Recorder's Notice of Trustee's Sale (NOTS) recordings.
- Maricopa County is the 4th most populous county in the US (~4.5M people), Phoenix MSA. High transaction volume expected across all lead types.
- The County Recorder portal (recorder.maricopa.gov) is the most important source for this county. It has WAF protection that blocks automated HTTP fetch but IS publicly accessible in a browser with no login and no payment for unofficial images. Playwright is the build strategy.
- The Superior Court dockets (civil, probate) and Justice Court (eviction) are fully accessible with no blockers — these can be built first while the Playwright recorder adapter is being developed.
- `jsonschema` Python module is not installed in the local environment. All v5.4.0 tests fail with `ModuleNotFoundError: No module named 'jsonschema'`. This is an environment setup issue, not a framework issue. Install with `pip install jsonschema` to enable schema validation.
